# CuentaClaro

Sitio web publicado en **[cuentaclaralaboral.com](https://cuentaclaralaboral.com)** con calculadoras laborales gratuitas para Colombia y una sección de servicios de páginas web para negocios pequeños.

## Qué incluye
- Calculadoras de liquidación, prima, cesantías, horas extra, salario neto, indemnización y vacaciones.
- Los cálculos se hacen en el navegador con JavaScript; no se guardan datos del usuario.
- Páginas de muestra para negocios (restaurante, hotel, salón y tienda).
- Diseño adaptable a celular, favicon, vista previa al compartir (Open Graph), sitemap y robots.txt.

## Tecnologías
HTML, CSS y JavaScript sin frameworks. Publicado con Cloudflare Pages a partir de este repositorio.
